# 🕒 Digital Clock

A simple and responsive Digital Clock built using HTML, CSS, and JavaScript. It displays the current time in real-time with a clean and attractive user interface.

## 🚀 About the Project

The Digital Clock is a frontend web development project that displays the current time and updates automatically every second.

This project helps practice JavaScript date and time functions, DOM manipulation, and CSS styling.

## ✨ Features

- 🕒 Displays current time in real-time
- 🔄 Automatically updates every second
- 🎨 Clean and modern user interface
- 📱 Responsive design
- ⏰ 12-hour or 24-hour time format (if implemented)

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
